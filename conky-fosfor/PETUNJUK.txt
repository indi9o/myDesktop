CONKY FOSFOR — PAKET PORTABEL

Target: Linux desktop Ubuntu/Debian dengan GNOME. Paling cocok layar 16:9.
Bukan aplikasi untuk Windows/macOS. Transparansi Conky dapat berbeda menurut desktop/compositor; pada Wayland Conky memakai dukungan X11/XWayland yang tersedia.

1. Pasang dependensi melalui terminal:
   sudo apt update
   sudo apt install conky-all python3 fonts-dejavu-core x11-xserver-utils

2. Ekstrak arsip, lalu buka terminal di folder Conky-Fosfor.
3. Jalankan dari sesi desktop pengguna biasa (jangan sudo):
   python3 install.py

Installer menyalin tema ke ~/.config/conky/Fosfor, mengatur wallpaper dan autostart, lalu mengganti Conky yang sedang berjalan. Cadangan konfigurasi terdahulu ada di ~/.config/conky/Fosfor-backups/. Tidak mengubah dock, ikon, atau panel GNOME.

Untuk menjalankan ulang:
   ~/.config/conky/Fosfor/start.sh

Untuk memulihkan tampilan sebelumnya:
   python3 ~/.config/conky/Fosfor/restore.py

Isi:
- Panel kiri bergaya sesi terminal fosfor hijau dengan pendar dan scanline
- Jam piksel, hari/tanggal Indonesia, cuaca Malang
- Meter CPU, RAM, SSD (kuning >= 75%, merah >= 90%)
- RAM tersedia, zram, jejak RAM fisik zram, swap SSD, SSD kosong, suhu CPU, uptime
- Jejak beban CPU tiga menit terakhir
- Wallpaper osiloskop CRT yang digambar prosedural

Metrik sistem setiap 3 detik. Persentase RAM menggunakan MemAvailable. Cuaca Open-Meteo untuk Malang setiap 15 menit, menampilkan CUACA TIDAK TERSEDIA bila data tidak tersedia/kedaluwarsa. Pembacaan suhu bergantung sensor kernel.

Lebar layout mengikuti monitor utama lewat xrandr. Untuk mengganti lokasi cuaca, ubah koordinat di theme/metrics.py dan label MALANG di theme/fosfor.lua sebelum memasang. Komputer tujuan tidak perlu memiliki zram; nilainya akan ditampilkan nol bila tidak ada.

Paket tidak menyertakan konfigurasi pribadi, kredensial, log, atau cadangan komputer asal.
